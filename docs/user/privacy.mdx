## The Veles app

- Veles has no internet permission, so Android does not let it use the network.
- Veles has no telemetry.
- One-time codes are read and handled on your phone.
- In this version Veles does not send your codes to any other device or service.
- Sharing codes with a computer over Bluetooth is still in development.

## This documentation site

This documentation site is hosted by Mintlify with telemetry turned off.
