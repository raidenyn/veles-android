---
title: "Grant notification access"
description: "Allow Veles to read bank notifications so it can show your code with a Copy button."
---

Veles can only clean up your bank codes if you allow it to read notifications. Android asks you to do this yourself.

## Steps

1. Open **Veles**. The screen shows a **PERMISSIONS** section.
2. Turn on the switch next to **Notification access**. Android opens its notification access settings. You can also get there with Settings, then Notifications, then Notification access (the exact path varies by phone).
3. Choose **Veles** and allow it.
4. Go back to Veles. It now shows **Notification listener enabled**. While access is missing it shows **Notification listener disabled** with the hint "Grant notification access below to turn it on".
5. Turn on the switch next to **Send notifications** too, so Veles can show its own clean notification.

<Note>
On Android 15 and later, Android hides one-time codes from apps unless an extra permission is granted. If Veles cannot read your codes, follow the [sensitive notifications guide](/docs/user/sensitive-notifications).
</Note>
