---
title: "Welcome to Veles"
description: "Veles turns noisy bank one-time-code notifications into a clean, copy-ready code on Android. Free, open source and offline."
---

Veles makes bank one-time codes (OTPs) easy to use. When your bank sends a long, cluttered message, Veles pulls out the three things that matter: the **code**, the **amount** and **who is charging you**. It then shows them in a clean notification with a one-tap **Copy** button.

```text
Your OTP is 674902 for payment of THB 1,250.00 to COFFEE HOUSE. Ref: 8842...
```

becomes

```text
674902 · THB 1,250.00 → COFFEE HOUSE      [ Copy ]
```

Tap **Copy**, switch back to your payment, paste the code and confirm. No squinting, no memorizing six digits.

## Who it is for

Anyone with an Android phone (Android 13 or later) who pays online and wants the bank code in one tap instead of hunting for it in a message.

## Free, open source and offline

- Free: no ads, no payments, no subscriptions.
- Open source: the full source code is public under the MIT license.
- Offline: Veles has no internet permission, so Android itself stops it from using the network.
